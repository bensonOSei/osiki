# osiki-sdk

Python SDK for [Osiki](../../README.md). It decides locally from a cached
snapshot, using a vendored copy of the engine's pure decision package
(`osiki_sdk/_decision`, generated by `scripts/sync_sdk_decision.py`; never edit
it by hand).

This is the scaffold; the public API lands in later M2a tasks.

## Development

```
poetry install
poetry run pytest --cov=osiki_sdk
```
